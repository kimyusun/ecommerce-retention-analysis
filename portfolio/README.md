# 온라인 쇼핑몰 성장성과 고객 유지 전략 분석

## 1. 프로젝트 개요

Prime Career 데이터 애널리스트 실무 과제에서 제공된 영국 온라인 쇼핑몰 거래 데이터를 바탕으로, 서비스의 성장성과 고객 유지 상태를 분석했다. 원본 과제 산출물은 SQL 결과와 단계별 엑셀 파일 중심이었기 때문에, 포트폴리오용으로는 분석 흐름과 의사결정 포인트가 드러나도록 재구성했다.

분석 질문은 세 가지로 정리했다.

1. 매출, 고객 수, 주문 수는 성장하고 있는가?
2. 신규 유입 고객은 다시 구매하고 있는가?
3. 비회원 주문은 서비스 성장에 어떤 기회를 만들고 있는가?

## 2. 데이터와 전처리 기준

원본 데이터는 부트캠프에서 제공된 `ecommerce_data.csv`이며, 2010년 12월 1일부터 2011년 12월 9일까지의 거래 라인 541,909건으로 구성되어 있다. 주요 컬럼은 거래 번호, 상품 코드, 수량, 거래 일시, 단가, 고객 ID, 국가다. 공개 GitHub 레포에는 원본 CSV를 포함하지 않고, 재현 시 로컬 `data/raw/ecommerce_data.csv` 위치에 직접 배치하도록 했다.

포트폴리오에서는 모든 지표가 같은 기준에서 계산되도록 아래 전처리 규칙을 적용했다.

| 단계 | 기준 | 남은 행 수 |
|---|---:|---:|
| 원본 데이터 | 전체 거래 라인 | 541,909 |
| 취소 거래 제거 | `InvoiceNo`가 `C`로 시작하는 건 제거 | 532,621 |
| 특수 상품 코드 제거 | `StockCode` 길이 5자 미만 제거 | 530,303 |
| 비정상 수량 제거 | `Quantity <= 0` 제거 | 528,967 |
| 비정상 단가 제거 | `UnitPrice <= 0` 제거 | 527,803 |
| 대량 이상치 제거 | `Quantity IN (80995, 74215)` 제거 | 527,801 |

이 기준을 고정한 이유는 기존 산출물 중 일부에서 2011년 1월 일평균 매출 값이 다르게 나타났기 때문이다. 원인은 `Quantity = 74215`인 대량 이상치 주문을 제거했는지 여부였다. 제거 전 2011년 1월 일평균 매출은 21,677.66, 제거 후는 19,187.86으로 계산된다. 포트폴리오에서는 이상치 제거 후 값을 기준으로 사용했다.

## 3. 핵심 지표

정제 후 데이터 기준 주요 수치는 다음과 같다.

| 지표 | 값 |
|---|---:|
| 정제 후 거래 라인 | 527,801 |
| 총 매출 | 10,040,391.76 |
| 고유 주문 수 | 19,784 |
| 고객 식별자 수 | 4,335 |
| CustomerID 결측 거래 라인 비중 | 24.91% |

월별 일평균 매출은 2011년 하반기부터 뚜렷하게 상승했다. 2011년 1월 일평균 매출은 19,187.86이었고, 2011년 11월은 48,592.52, 2011년 12월은 49,671.89였다. 특히 11월과 12월은 연말 선물 수요와 도매성 대량 주문이 함께 작용한 피크 구간으로 해석할 수 있다.

## 4. 인사이트

### 인사이트 1. 하반기 성장세는 분명하지만, 11월 피크의 성격을 분리해서 봐야 한다

매출, 고객 수, 주문 수 모두 2011년 하반기부터 상승했다. 단순히 “서비스가 성장했다”고 말할 수는 있지만, 11월 피크는 일반 고객 증가만으로 설명하기 어렵다. 비회원 고액 주문이 동시에 증가했기 때문이다.

따라서 11월 성장은 두 층으로 나누어 해석해야 한다.

1. 시즌성 수요 증가: 연말 선물/도매 주문 가능성
2. 고액 비회원 주문 유입: 주문 수보다 객단가 영향이 큰 성장

### 인사이트 2. 재구매율은 첫 달 급락 후 20~30%대에서 유지된다

회원 고객만 대상으로 코호트 리텐션을 계산하면, 첫 구매 후 1개월 차 평균 재구매율은 20.45% 수준이다. 대부분의 코호트는 첫 달에 크게 이탈한 뒤 20~30%대에서 유지되는 패턴을 보인다.

2010년 12월 코호트는 11개월 후 재구매율이 50.17%로 높게 나타난다. 다만 이 데이터는 2010년 12월부터 관측되기 시작하므로, 해당 코호트에는 실제 신규 고객이 아니라 이전부터 구매하던 기존 고객이 섞였을 가능성이 있다. 그래서 이 수치는 “장기 유지력이 높은 고객군이 존재한다”는 신호로 보되, 순수 신규 고객 리텐션으로 과대 해석하지 않아야 한다.

### 인사이트 3. 비회원 주문은 적지만, 고액 주문 기회가 크다

2011년 11월 비회원 주문 비중은 3.96%에 불과했지만, 비회원 매출 비중은 21.65%였다. 같은 달 비회원 주문당 평균 매출은 2,895.41로 매우 높았다.

즉, 비회원 주문은 “많이 발생하는 저가 주문”이 아니라 “적게 발생하지만 매출 기여가 큰 주문”에 가깝다. 이 경우 무조건 회원가입을 강제하기보다, 고액 비회원 구매자를 식별하고 추후 B2B 리드나 재구매 고객으로 전환하는 전략이 더 적합하다.

## 5. 실행 제안

1. Q4 시즌성 수요를 사전 주문 캠페인으로 제도화한다.
   9~10월부터 대량 주문 견적, 선물 세트, 도매 패키지, 배송 마감일 안내를 제공해 11월 피크를 우연한 이벤트가 아니라 반복 가능한 매출 기회로 만든다.

2. 고액 비회원 주문자를 회원 또는 B2B 리드로 전환한다.
   결제 직후 계정 생성, 세금계산서/영수증 관리, 재주문 할인, 담당자 상담 신청 같은 혜택을 제시하면 구매 흐름을 방해하지 않으면서 고객 데이터를 확보할 수 있다.

3. 첫 구매 후 30일 이내 리텐션 캠페인을 설계한다.
   +1개월 리텐션이 낮기 때문에 구매 직후 7일, 21일, 30일 리마인드 메시지와 연관 상품 추천을 운영해 초기 이탈을 줄인다.

4. 여름철 저조 구간을 별도 캠페인으로 관리한다.
   봄·여름 유입 고객의 재구매율이 낮고, 월별 KPI도 상대적으로 약하다. 시즌이 약한 구간에는 할인보다 재구매 트리거가 있는 상품 번들, 재고 소진 프로모션, B2B 반복 구매 혜택을 우선 검토한다.

## 6. 한계와 추가 개선 방향

이 분석은 거래 로그만 기반으로 하므로 유입 채널, 캠페인, 상품 카테고리, 회원가입 시점, 실제 고객 세그먼트는 확인할 수 없다. 따라서 11월 비회원 고액 주문이 특정 마케팅 캠페인 때문인지, 계절성 때문인지, 특정 상품군 때문인지는 추가 데이터 없이는 확정할 수 없다.

포트폴리오를 더 발전시키려면 다음 작업을 추가하면 좋다.

1. 상품 카테고리 또는 상위 SKU별 11월 매출 기여도 분석
2. 비회원 고액 주문의 국가, 상품, 주문 규모 분석
3. 첫 구매 후 30일/60일 재구매 고객과 이탈 고객의 구매 상품 비교
4. Tableau, Looker Studio, Power BI 중 하나로 대시보드 제작
